# Profiles for NXOSC Reborn, in Supperware Bridgehead's profile.txt format:
#   https://supperware.net/headtracker/profile-txt/
#
# Each profile is four or more lines -- name, OSC address, parameters, then
# one or more destinations -- separated by a blank line. Lines starting with
# # are comments and can go anywhere.
#
# ADDRESSES
#   /[a,b,c]  sends a separate message per name: /a, /b, /c. One value each,
#             which is the form a DAW or plugin can bind to a control.
#   /abc      sends a single message carrying all the values as an array.
#
# PARAMETERS
#   Angles      yaw, pitch, roll -- degrees unless a suffix says otherwise
#   Quaternion  qw, qx, qy, qz
#               Use angles or quaternion components, not both.
#   Suffixes    :r radians   :1 maps to -1..1   :0 maps to 0..1
#   Modifiers   leading -  reverses      each trailing _  adds 90 degrees
#               so -yaw__ is reversed yaw plus 180
#   Padding     0 sends a zero, s:text sends a constant string
#
# DESTINATIONS
#   "local 8000", "127.0.0.1 8000" or just "8000". One per line; data goes
#   to all of them.
